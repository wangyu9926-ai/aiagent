# 数据库分析技能

你被要求查询服务端数据库。数据库凭据和连接只存在于服务端，永远不会出现在对话或浏览器里。

## 先看权限

1. 先调用 `datalab_databases`，只使用返回列表里的连接。
2. 如果用户想要的库/指标不在列表里，直接说“当前账号没有这个数据的权限”，不要猜测、不要尝试其他连接、不要向用户索要数据库密码。
3. 一个连接只代表用户被批准的那一部分数据；不要假设同一台数据库上的其他表也可查。

## 查询规则

- 只写只读 `SELECT` 或 `WITH` 查询，单条语句；不要写 DDL/DML、不要多语句、不要读文件或外部数据库。
- 先看表结构和少量样本，再写聚合；默认加 `LIMIT`，不要拉全表。
- 不查询与问题无关的个人信息、密钥、账号表。
- 查询被拒绝时，把“无权限/连接不存在”如实告诉用户，不要换连接绕过。
- 结果给出连接名、表名、时间范围和口径；数字必须来自工具返回，不要编造。

## 输出

- 先给结论摘要，再给明细/分组表。
- 如果用户需要图表，可以把查询结果通过 `datalab_query` 的本地文件分析方式生成，或说明当前数据库工具只返回表格。
- 最后列出权限限制、口径假设和数据质量问题。
