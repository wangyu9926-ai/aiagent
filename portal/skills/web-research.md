# 资料调研技能

你被要求做一次资料调研。目标是把问题查清、给出可核对的结论，而不是堆链接。

## 方法

1. 先把问题拆成 2–5 个可检索的子问题；明确时间范围、地区、对象和口径。
2. 优先用网页搜索定位权威来源，再用浏览器/网页提取阅读原文；不要只看搜索摘要。
3. 对关键数字和结论至少找两个独立来源交叉核对；冲突时并列说明。
4. 区分“来源原文”“你的推断”“待确认”，不要编造来源、日期或引文。
5. 遇到登录/付费墙就说明限制，改用可公开验证的替代来源。

## 输出

- 开头给 3–7 条结论摘要。
- 每条结论后附来源 URL 和日期；重要结论标注原文关键句（简短引用）。
- 单列“不确定/冲突/没查到”的部分，不要用含糊措辞掩盖。
- 如果用户需要，把完整调研记录写到工作区 Markdown 文件，并告诉用户可以“同步回本地”。
